# DocTick (macOS)

## Çalıştır
**`baslatMAC.command`** → **sağ tıkla → Aç** (ilk seferde güvenlik uyarısı çıkarsa tekrar "Aç").

- .NET 10 yoksa otomatik kurulur (sudo/yönetici **istemez**, yalnızca bir kez).
- Kurulum bitince tarayıcıda açılır: **http://localhost:5080**
- Frontend önceden derlenmiş halde gelir → **Node/npm gerekmez**, build hatası olmaz.

## Giriş
"Google ile giriş yap" → test sürümünde **anında onaylı**, hemen randevu alabilirsin.

## Durdur
Açılan **Terminal** penceresini kapat (Ctrl+C).
