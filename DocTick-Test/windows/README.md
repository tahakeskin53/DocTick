# DocTick (Windows)

## Çalıştır
**`DocTick_App.bat`** dosyasına **çift tıkla**. Hepsi bu.

- .NET 10 yoksa otomatik kurulur (yönetici yetkisi **istemez**, yalnızca bir kez).
- Kurulum bitince tarayıcıda açılır: **http://localhost:5080**
- Frontend önceden derlenmiş halde gelir → **Node/npm gerekmez**, build hatası olmaz.

## Giriş
"Google ile giriş yap" → test sürümünde **anında onaylı**, hemen randevu alabilirsin.

## Durdur
Açılan **"DocTick App (5080)"** siyah penceresini kapat (Ctrl+C).
