# Admin paneli UI kiti

DocTick admin yüzeyi: genel bakış (istatistik + bugünün randevuları), bölüm yönetimi (aç/kapa, ekle), doktor yönetimi, haftalık randevu saati ızgarası, e-posta bildirim ayarları + hatırlatma şablonu önizlemesi.

- `index.html` — tıklanabilir panel (giriş noktası)
- `AdminSidebar.jsx`, `AdminPanel.jsx`, `AdminBolumler.jsx`, `AdminDoktorlar.jsx`, `AdminSaatler.jsx`, `AdminEposta.jsx`, `admin-app.jsx`

Not: Kaynak codebase'te UI olmadığı için sıfırdan, design system foundations'a göre tasarlandı.
