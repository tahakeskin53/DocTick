- `index.html` — tıklanabilir akış (giriş noktası)
- `HastaTopBar.jsx`, `HastaHome.jsx`, `HastaBooking.jsx`, `HastaRandevular.jsx`, `hasta-app.jsx`, `data.js` (sahte veri)

Not: Kaynak codebase'te UI olmadığı için bu ekranlar sıfırdan, design system foundations'a göre tasarlandı — mevcut bir ürünün birebir kopyası değildir.
