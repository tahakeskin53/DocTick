Eylem butonu; sayfa başına tek `primary`, ikincil eylemler `secondary`/`ghost`, iptal/silme `danger`.

```jsx
<Button onClick={confirm}>Randevuyu onayla</Button>
<Button variant="secondary">Geri</Button>
<Button variant="danger" size="sm">Randevuyu iptal et</Button>
```

Varyantlar: primary/secondary/ghost/danger · boyutlar sm/md/lg · `disabled`.
